This is the fighter management spring boot microservice that was created for the boxing management application. 
It lets you add and update fighters to the database. This will help us keep track of the fighters we have in the system,
what their record is, where they reside, and their weight and height, all of which are factors that are important for 
scheduling fighters for different fights. The current state that it is in right now is just the first phase as there will be
additional enhancements and bug fixes for additional features such as adding a column to the screen that will signal
that a fighter has been booked for a fight.
